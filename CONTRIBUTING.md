# Правила работы с репозиторием сайта

Проект: сайт бренда SYSOPS · DEVOPS · OPSOPS EXPERTISE. Язык контента — русский. Стиль — Cyber / Dark / Professional Engineering.

## Обязательные правила
- Не публиковать сайт и не пушить без разрешения владельца.
- Не придумывать отзывы, статистику, гарантии трудоустройства/дохода, дефицит мест, таймеры.
- Данные о курсах — только из Stepik (или от владельца). Не выдумывать уроки и функции.
- Закрытые курсы (`status: "private"`) не показывать как общедоступные и не публиковать ссылки-приглашения.
- Сведения об OpsDeck — только из его репозитория. Сам репозиторий OpsDeck не менять.
- Не хранить в репозитории токены, ключи и приватные материалы курсов.
- Изображения — только свои или с проверенной лицензией.

## Технические соглашения
- Все внутренние ссылки — через `url()` из `src/lib/url.ts` (base path для GitHub Pages).
- Новый курс = новый JSON в `src/data/courses/`, компоненты не трогать.
- Цвета и отступы — токены из `src/styles/global.css`, без хардкода новых цветов.
- Перед коммитом: `npm run check && npm run build`.
- Аналитика считает переходы на Stepik, а не записи на курс — так и называть.
